  <name>Task 1: Create css/tokens.css — two-tier design token system</name>
  <files>css/tokens.css</files>
  <action>
Create the directory `css/` then create `css/tokens.css` with a `:root` block containing ALL design tokens in two tiers.

Tier 1 — Primitives (raw palette values, never referenced by HTML directly):
```css
/* === PRIMITIVES === */
--hue-primary: 270;
--hue-accent: 180;

--purple-600: hsl(270, 60%, 60%);
--purple-700: hsl(270, 50%, 45%);
--purple-900: hsl(270, 15%, 8%);
--cyan-400: hsl(180, 90%, 65%);
--cyan-500: hsl(180, 80%, 55%);
--white: hsl(0, 0%, 92%);
--white-muted: hsl(0, 0%, 60%);
--white-faint: hsl(0, 0%, 30%);
```

Tier 2 — Semantic tokens (role-based aliases; these are what all other CSS files use):
```css
/* === SEMANTIC: Colors === */
--color-bg: var(--purple-900);
--color-surface: hsla(270, 20%, 15%, 0.6);
--color-text: var(--white);
--color-text-muted: var(--white-muted);
--color-text-faint: var(--white-faint);
--color-primary: var(--purple-600);
--color-primary-hover: var(--purple-700);
--color-accent: var(--cyan-500);
--color-accent-bright: var(--cyan-400);
--color-border: hsla(0, 0%, 100%, 0.08);

/* === SEMANTIC: Glass effect (Phase 3 will use; tokens defined now) === */
--glass-blur: 12px;
--glass-bg: hsla(270, 20%, 15%, 0.25);
--glass-border: hsla(0, 0%, 100%, 0.08);
--glass-shadow: 0 8px 32px hsla(270, 60%, 5%, 0.4);

/* === SEMANTIC: Spacing (4px base, rem units) === */
--space-xs: 0.25rem;
--space-sm: 0.5rem;
--space-md: 1rem;
--space-lg: 2rem;
--space-xl: 4rem;
--space-2xl: 8rem;

/* === SEMANTIC: Typography === */
--font-body: 'Inter', system-ui, sans-serif;
--font-heading: 'Space Grotesk', var(--font-body);
--text-sm: 0.875rem;
--text-base: 1rem;
--text-lg: 1.125rem;
--text-xl: 1.25rem;
--text-2xl: 1.5rem;
--text-4xl: 2.25rem;
--leading-tight: 1.2;
--leading-normal: 1.6;

/* === SEMANTIC: Border radii === */
--radius-sm: 0.375rem;
--radius-md: 0.75rem;
--radius-lg: 1.25rem;
--radius-full: 9999px;

/* === SEMANTIC: Transitions (Phase 3 will use; defined now) === */
--transition-fast: 150ms ease;
--transition-base: 300ms ease;
--transition-slow: 600ms ease;
```

IMPORTANT: `--color-surface`, `--glass-bg`, `--glass-border`, `--glass-shadow` contain raw hsla() values because they need opacity — this is the ONLY place where raw color values are allowed. All other CSS files MUST use only var(--*) tokens.

Add a comment at the top of the file:
```css

 * tokens.css — ALL design tokens live here.
 * NO color, spacing, or typography values belong in any other CSS file.
 * Other files: use var(--token-name) exclusively.
 */
```

<task type="auto" tdd="false">
  <name>Task 2: Create css/reset.css — minimal browser normalization</name>
  <files>css/reset.css</files>
  <action>
Create `css/reset.css`. This file MUST NOT contain any color, spacing, or font values — use ONLY structural rules. No var() references needed here since reset.css loads before tokens.css in the cascade but after it in document order.

Write these exact rules:

```css
/*
 * reset.css — Minimal browser normalization.
 * Structural rules only. No color/spacing/font values — those live in tokens.css.
 * Load order: reset.css FIRST, then tokens.css, layout.css, components.css, animations.css
 */

*, *::before, *::after {
  box-sizing: border-box;
}

* {
  margin: 0;
  padding: 0;
}

html {
  scroll-behavior: smooth;
}

@media (prefers-reduced-motion: reduce) {
  html {
    scroll-behavior: auto;
  }
}

body {
  -webkit-font-smoothing: antialiased;
  -moz-osx-font-smoothing: grayscale;
  min-height: 100vh;
}

img, picture, video, canvas, svg {
  display: block;
  max-width: 100%;
  height: auto;
}

input, button, textarea, select {
  font: inherit;
}

p, h1, h2, h3, h4, h5, h6 {
  overflow-wrap: break-word;
}

/* Remove list styles on ul/ol with explicit role */
ul[role='list'],
ol[role='list'] {
  list-style: none;
}

/* Remove default focus styles — will be replaced in components.css */
:focus-visible {
  outline: 2px solid transparent;
  outline-offset: 2px;
}
```

DO NOT add: any color values, background declarations, font-family, font-size, or any value that belongs in tokens.css.
