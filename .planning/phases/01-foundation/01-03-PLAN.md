Create the directory structure `assets/fonts/` and download the two variable font files.

Download Inter variable font (Latin subset) from Google Fonts API:
```bash
mkdir -p C:/Users/calla/source/repos/become-a-dev/assets/fonts
mkdir -p C:/Users/calla/source/repos/become-a-dev/assets/images
mkdir -p C:/Users/calla/source/repos/become-a-dev/assets/icons

# Download Inter variable WOFF2 (Latin subset, variable weight 100-900)
curl -L "https://fonts.googleapis.com/css2?family=Inter:wght@100..900&display=swap" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)" \
  -o /tmp/inter-css.txt 2>/dev/null

# Extract the WOFF2 URL from the CSS response and download
INTER_URL=$(grep -o "https://fonts.gstatic.com/s/inter/[^)]*\.woff2" /tmp/inter-css.txt | head -1)
curl -L "$INTER_URL" -o "C:/Users/calla/source/repos/become-a-dev/assets/fonts/inter-variable.woff2"

# Download Space Grotesk variable WOFF2 (Latin subset, variable weight 300-700)
curl -L "https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@300..700&display=swap" \
  -H "User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64)" \
  -o /tmp/space-grotesk-css.txt 2>/dev/null

SPACE_URL=$(grep -o "https://fonts.gstatic.com/s/spacegrotesk/[^)]*\.woff2" /tmp/space-grotesk-css.txt | head -1)
curl -L "$SPACE_URL" -o "C:/Users/calla/source/repos/become-a-dev/assets/fonts/space-grotesk-variable.woff2"
```

Write this exact HTML:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Become a Dev — Portfolio</title>
  <meta name="description" content="A developer portfolio built in the open — every project is something built during the learning journey." />

  <!--
    Self-hosted variable fonts — no external CDN request.
    font-display: swap ensures text is visible during font load.
    font-weight range covers full variable axis for each font.
  -->
  <style>
    @font-face {
      font-family: 'Inter';
      src: url('assets/fonts/inter-variable.woff2') format('woff2');
      font-weight: 100 900;
      font-style: normal;
      font-display: swap;
    }

    @font-face {
      font-family: 'Space Grotesk';
      src: url('assets/fonts/space-grotesk-variable.woff2') format('woff2');
      font-weight: 300 700;
      font-style: normal;
      font-display: swap;
    }
  </style>

  <!--
    CSS load order is load-bearing — do not reorder.
    reset.css: browser normalization (no values)
    tokens.css: ALL design tokens (color, spacing, type, radius)
    layout.css: page structure, grid, typography — consumes tokens
    components.css: UI components — consumes tokens
    animations.css: js-enabled gate and motion — consumes tokens
  -->
  <link rel="stylesheet" href="css/reset.css" />
  <link rel="stylesheet" href="css/tokens.css" />
  <link rel="stylesheet" href="css/layout.css" />
  <link rel="stylesheet" href="css/components.css" />
  <link rel="stylesheet" href="css/animations.css" />
</head>
<body>

  <!-- Skip to main content: visible on focus, hidden otherwise (layout.css .skip-link) -->
  <a href="#main-content" class="skip-link">Skip to main content</a>

  <header class="site-header">
    <nav class="site-nav" aria-label="Main navigation">
      <!-- Phase 2: nav links (Home, Projects, Skills, About, Contact) -->
    </nav>
  </header>

  <main id="main-content">

    <!-- Hero: above the fold, no data-animate (already visible on load) -->
    <section id="hero" class="section section--hero">
      <!-- Phase 2: h1 with name, role, and one-line pitch -->
      <!-- Placeholder h1 so heading hierarchy is valid in Phase 1 -->
      <h1><!-- Phase 2 --></h1>
    </section>

    <!-- Projects: data-animate = Phase 3 will trigger reveal on scroll -->
    <section id="projects" class="section" data-animate>
      <h2>Projects</h2>
      <!-- Phase 2: card grid of built projects -->
    </section>

    <!-- Skills: data-animate = Phase 3 scroll reveal -->
    <section id="skills" class="section" data-animate>
      <h2>Skills</h2>
      <!-- Phase 2: skill levels for HTML/CSS, JS, TS, Python/AI -->
    </section>

    <!-- About: data-animate = Phase 3 scroll reveal -->
    <section id="about" class="section" data-animate>
      <h2>About</h2>
      <!-- Phase 2: background, career direction, currently learning -->
    </section>

    <!-- Contact: data-animate = Phase 3 scroll reveal -->
    <section id="contact" class="section" data-animate>
      <h2>Contact</h2>
      <!-- Phase 2: links to reach out -->
    </section>

  <footer class="site-footer">
    <!-- Phase 2: copyright, links -->
  </footer>

    defer: script executes after HTML is parsed (non-blocking).
    main.js adds js-enabled class to <html>, activating CSS animation gate.

</body>
</html>
```
