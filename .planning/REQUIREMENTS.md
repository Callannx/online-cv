# Requirements: Become a Dev — Portfolio

**Defined:** 2026-03-31
**Core Value:** A living proof-of-work: every project on the site is something built *during* the learning journey, so the portfolio itself grows as skills grow.

## v1 Requirements

### Foundation

- [ ] **FNDN-01**: User sees a dark-themed page with purple/cyan color palette applied consistently via CSS custom properties
- [ ] **FNDN-02**: User sees the page render correctly on mobile, tablet, and desktop viewports
- [ ] **FNDN-03**: Page content is readable and accessible without JavaScript (progressive enhancement)

### Sections

- [ ] **SECT-01**: User sees a hero section with name, role title, and one-line pitch
- [ ] **SECT-02**: User sees a skills section showing HTML/CSS, JavaScript, TypeScript, and Python/AI proficiency
- [ ] **SECT-03**: User sees a projects section as a card grid where each card links to a project or repo
- [ ] **SECT-04**: User sees an about section with background, career direction, and what's being learned
- [ ] **SECT-05**: User sees a contact section with links to reach out

### Visual

- [ ] **VISUL-01**: User sees glassmorphism-styled cards with backdrop blur and semi-transparent backgrounds
- [ ] **VISUL-02**: User sees content sections animate in as they scroll into view
- [ ] **VISUL-03**: User sees hover micro-interactions on buttons, cards, and links

### Deployment

- [ ] **DEPL-01**: User can access the live site at a GitHub Pages URL
- [ ] **DEPL-02**: Site shows correct preview image and title when shared on social media (OG meta tags)
- [ ] **DEPL-03**: User sees a custom 404 page instead of GitHub's default
- [ ] **DEPL-04**: Site has a favicon

## v2 Requirements

### Content

- **CONT-01**: Blog section with learning posts
- **CONT-02**: Case study detail pages per project

### Enhancement

- **ENHN-01**: GitHub Actions CI — validate HTML/CSS, run Lighthouse on deploy
- **ENHN-02**: Image optimization workflow for project screenshots

## Out of Scope

| Feature | Reason |
|---------|--------|
| Backend or CMS | Static site only — no server-side rendering needed for v1 |
| Blog | Defer until there's content to write |
| Mobile app version | Responsive web is sufficient |
| React or other frameworks | Deliberately plain HTML/CSS/JS as a learning exercise |
| Animation libraries (GSAP etc.) | CSS + Intersection Observer is sufficient and keeps zero dependencies |
