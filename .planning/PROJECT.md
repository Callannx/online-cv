# Become a Dev — Portfolio

## What This Is

A personal portfolio website for a Front End Developer transitioning into AI development. Built with plain HTML, CSS, and JavaScript, it showcases projects built while learning — starting with web fundamentals, progressing through TypeScript, and into Python/AI work. Designed to work for both job applications and freelance opportunities.

## Core Value

A living proof-of-work: every project on the site is something built *during* the learning journey, so the portfolio itself grows as skills grow.

## Context

- Developer is a Front End Developer with foundational HTML/CSS knowledge, learning JavaScript and TypeScript
- Current role involves AI projects — building Python/AI skills to match
- Wants to use AI-assisted, structured development workflow (plan-first, verify before done, self-improvement loop)
- Visual inspiration: @designmotionhq — dark backgrounds, deep purple/cyan/teal accents, glassmorphism, bold typography, motion-forward, card-based layouts
- Repo: `become-a-dev` on GitHub, targeting GitHub Pages hosting

## Constraints

- **Tech Stack**: Plain HTML/CSS/JS only — no frameworks, no build tools for v1. Deliberately chosen as a learning exercise
- **Content**: V1 is the shell — structure and design right first, project content fills in as learning progresses
- **Hosting**: GitHub Pages — static files only, no server-side rendering
